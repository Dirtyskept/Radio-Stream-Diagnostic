ffprobe.exe: licence and source notice
======================================

What it is
----------
ffprobe.exe in this folder is part of FFmpeg (https://ffmpeg.org), version
5.1, as built by Emby (version string "5.1-emby_2023_06_25_p6"). It was taken
unchanged from an Emby Server installation. It is a separate program: the
diagnostic script only runs it and reads its output.
