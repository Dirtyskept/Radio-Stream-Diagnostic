Optional Portable FFprobe
=========================

This diagnostic archive includes ffprobe.exe in this folder so it can run without
depending on the Emby installation or system PATH. If it fails to start on your
Windows system, try a compatible trusted build and keep any required runtime DLLs
beside ffprobe.exe. The HTML title report only extracts title-like fields from the
FFprobe JSON output; it does not embed the executable path or stream URL.
